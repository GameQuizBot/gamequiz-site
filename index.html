BUILT FOR DAILY PLAY

A short daily ritual, long-term competition and enough control for every server to make GameQuiz its own.

🧠

DAILY QUIZ

A fresh challenge every day

Choose 1, 2 or 3 automatic quizzes per day, with consecutive time slots across your server's schedule. Answers stay private and editable until each quiz closes, then the correction reveals the results.

TODAY'S QUIZ Classic: +1 / +2 / +3 points
Answer whenever you want before the deadline. 🔒 No speed bonus — everyone gets the same chance.

Plan ahead with /schedule: see today's remaining quizzes and the next six days, in your server's time zone.

🏆

MONTHLY COMPETITION

Compete for the season.

Every server has its own monthly season and all-time leaderboard. Track ranks, accuracy, streaks, image-quiz performance and long-term progress. Daily quiz scores and player rankings belong to the server where you play.

IMAGE QUIZZES

Which game is this image from?

Recognize a game from a screenshot and earn 3 points for a correct answer. Admins choose the image-quiz weekdays. On those days, one image round takes the first slot and counts toward the daily total; the other slots use classic questions.

INSIDE GAMEQUIZ V1.0.0

Made to feel native inside Discord.

Questions, corrections, profiles and achievements stay compact, readable and useful without flooding the channel.

Use /leaderboard for your server's monthly standings and /global_leaderboard for its all-time standings. Screenshots show example data, not live player or server totals.

CONFIGURE IT FOR YOUR SERVER

Flexible without becoming complicated.

Administrators can adjust GameQuiz directly in Discord with /configure: schedules, content filters, notifications and more, all in one interface.

🕒

Schedule & reminders

Set 1, 2 or 3 daily quizzes, start and closing times, time zone, reminder timing and notification pings.

🖼️

Quiz format by weekday

Select image days. One 3-point image round replaces the first classic question within your daily total.

🎛️

Content filters

Choose categories and difficulties for classic questions, plus genres and platforms. Use the updated selection menus to save your preferences.

📺

Channel, role & language

Move the quiz channel, change the notification role or switch the server between English and French.

⏸️

Pause without losing progress

Temporarily stop new automatic quizzes, then resume later while preserving rankings and history.

🧪

Administrator tools

Check configuration and permissions, run test quizzes, close or cancel a quiz, and adjust points when needed.

SUPPORT & DATA CONTROLS

Useful tools when something goes wrong.

🚩

Report a quiz problem privately

Use /report to send a problem to the GameQuiz team with the relevant quiz context attached. Track the conversation and reply with /my_reports.

🔐

Player data controls

Users can export their active server data with /my_data and delete it with /delete_my_data, including linked GameQuiz reports.

🗑️

Server-level deletion

Administrators can permanently delete the server's active GameQuiz data with /delete_server_data after confirmation.

See the Privacy Policy for retention details and the Terms of Service for the rules governing GameQuiz.
