IMAGE QUIZZES

Which game is this image from?

Image rounds are worth 2 points. Server admins choose which weekdays use image quizzes. GameQuiz prioritizes Steam Store screenshots, falls back to IGDB when needed, and applies a light local title check before publishing.

CONFIGURE IT FOR YOUR SERVER

Flexible without becoming complicated.

Administrators can change the important parts directly from Discord with /configure, without editing deployment variables.

🕒

Schedule & reminders

Choose posting and closing times, time zone, reminder timing and which messages ping the Quiz role.

🖼️

Quiz format by weekday

Choose exactly which days use image rounds and which days use standard questions.

🎛️

Content filters

Include or exclude categories, difficulties, genres and platforms to better fit your community.

📺

Channel, role & language

Move the quiz channel, change the notification role or switch the server between English and French.

⏸️

Pause without losing progress

Temporarily stop new automatic quizzes, then resume later while preserving rankings and history.

🧪

Built-in checks & tests

Admins can verify configuration and permissions, publish test questions and manually close a test when needed.

SUPPORT & DATA CONTROLS

Useful tools when something goes wrong.

🚩

Report a quiz problem privately

Use /report / /signaler to send a problem to the GameQuiz team with the useful quiz context attached. Track the conversation with /my_reports.

🔐

Player data controls

Users can export their active server data with /my_data and delete it with /delete_my_data, including linked GameQuiz reports.

🗑️

Server-level deletion

Administrators can permanently delete the server's active GameQuiz data with /delete_server_data after confirmation.

See the Privacy Policy for retention details and the Terms of Service for the rules governing GameQuiz.
