🎮 GameQuiz

The daily video game quiz for Discord. One quiz per day, private answers while the quiz is open, seasonal and all-time leaderboards, profiles, achievements and image quizzes.

Add GameQuiz to Discord Support server

🧠 Daily quiz

One automatic quiz every day. No speed advantage: players can answer while the quiz is open.

🏆 Competition

Seasonal rankings, all-time rankings, personal profiles, statistics and achievements.

🌍 International

Server content can be configured in English or French. Slash-command names are localized by Discord for each user.

Get started

Install GameQuiz on a Discord server, then use /setup. A member with the required server-management permission must complete the setup.

Video-game information and images used by image quizzes may be provided by IGDB. Game names, trademarks and game imagery remain the property of their respective rights holders.
