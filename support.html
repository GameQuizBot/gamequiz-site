Need help with setup, found a quiz error or want to suggest an improvement? Choose the most convenient option below.

Report directly in GameQuiz

For a quiz error or GameQuiz problem, use /report. When relevant, GameQuiz can attach the useful quiz context so the issue is easier to identify.

Use /my_reports to follow your reports and reply to the GameQuiz team.
